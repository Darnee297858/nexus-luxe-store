# 🛍️ Nexus Luxe Store

An elegant, modern, and responsive e-commerce storefront crafted with React, Vite, and Tailwind CSS. Featuring real-time product search, interactive category filtering, dynamic shopping cart management, and dark mode support.

---

## ✨ Features

- 🎨 **Modern & Luxe UI:** Sleek aesthetic, responsive layout, and smooth UI transitions.
- 🔍 **Real-Time Product Search & Filtering:** Filter items by category or instantly search through products.
- 🛒 **Interactive Shopping Cart:** Dynamic updates, item quantities, and real-time total price calculations.
- 🌙 **Dark Mode Support:** Effortlessly toggle between light and dark visual themes.
- ⚡ **Blazing Fast:** Built on Vite for lightning-quick build times and performance.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React (Vite)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Deployment:** Vercel
